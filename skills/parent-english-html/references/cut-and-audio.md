# 分段音频切点：原理、判据与踩过的坑

> 这一份是「逐句精听音频末尾老是多出后一句几个词」这件事的完整复盘。
> 日常操作看 `SKILL.md`；这里只讲**为什么这么写**，以及别再走回去的弯路。

## 1. 切点是怎么来的（不要退回 OCR 帧时间）

最早的切点是这样推的：

```
b = 下一条烧录字幕出现的时间 + 0.15
```

问题在于 `work_ocr/NN.jsonl` 的帧时间来自 **1 秒 1 帧**的抽帧，`t` 是整数秒；
而烧录字幕又总比语音早出现一点。两者叠加 → 切点系统性偏晚最多 1 秒。
后果就是**每一段音频末尾都多带出后一句的头几个词**。

正确做法是拿**词级时间**（whisper `word_timestamps=True`）：

```
a = 首词时刻 − PAD_HEAD(0.30)，且不早于「上一个词说完」
b = min(末词时刻 + TAIL(0.12), 末词时刻 + 与下一个词起点之间的中点)
```

「与下一个词的中点」这一步是关键：连读时中点≈真实边界，有停顿时中点落在静音里（无害）。

## 2. 怎么把「整课文本」对到「整片转录」上

`cutfit.align()` 做一次全局单调对齐（Needleman–Wunsch），把

* A = 整课 part2 的英文按段拼起来的**词序列**（顺序固定）
* B = 整片转录的词序列（带时间）

对上，得到「每个 A 词 → 转录下标」。打分用字符相似度：
`MATCH 1.0 / NEAR 0.45 / MIS −1.0 / GAP −0.65`（NEAR 用来容忍 OCR 与 ASR 的
拼写差异，例如 `abc's` / `abcs`）。

两个必须踩到的实现细节：

* `key()` 的正则要匹配**非**词字符再 `sub` 掉 —— 写成 `[a-z0-9']+` 会把字母全删掉，
  对齐直接返回 0 对（症状：`--stat` 报「段数 0」）。
* A 必须**按词展平成一整条**（`[key(w) for t in texts for w in t.split()]`），
  不能按段（9 个元素），否则跟按词的 spans 不同长，覆盖率恒为 0。

## 3. 尾部护栏：看语义证据，不要写死秒数

一开始用 `b 不许比原值早超过 MAX_TRIM=1.30s` 兜底。结果是**大量段正好停在
`b-1.30`** —— 护栏卡住了本该更狠的收敛，残留照旧。

改成看**语义证据**：

| 证据 | 含义 | 处理 |
|---|---|---|
| `miss_tail = (本段词数−1) − 末个命中词的下标` ≤ 1 | 本段末尾的词都对上了 → `t_end` 可信 | 按词级时间收尾，甚至允许**回补** |
| `miss_tail` > 1 或覆盖率 < 0.60 | 末尾没对上 → `t_end` 可能是错的 | 只做保守回收：覆盖率 ≥0.80 收 3.0s / ≥0.60 收 1.9s / 更低收 1.3s |

**「回补」必须允许**：OCR 抽帧精度只有 1 秒，有时会把一段的终点定得过早，
于是**页面文本比音频长**。实例：07 课把整首字母歌写进了一段 3.5 秒的音频
（`b=18.15` 而末词说完在 31.7 秒）。这时 `t_end` 明显晚于 `b_old`，只要末尾
的词都对上，就把 `b` 往后放到「下一个词起点之前」；上界用**下一段精修后的 `a`**
来卡（所以要先算完所有的 `a`，再算 `b`），不会串段。

## 4. 三个会伪造证据的陷阱

### 4.1 VAD 会把你 90% 的语音当噪声

faster-whisper 默认 `vad_filter=True`（Silero）。**室内低声说话 / 边玩边喊**的课
（躲猫猫、游乐场、坐车、玩沙子）会被滤掉 **85%–98%** 的语音：

| 课 | 默认 VAD 命中 | 关 VAD 命中 |
|---|---|---|
| 17 躲猫猫 | 3 / 153 词（2%） | 108 / 153（71%） |
| 20 游乐场2 | 13 / 215（6%） | 199 / 215（93%） |
| 23 坐车 | 29 / 203（14%） | 180 / 203（89%） |

后果不只是转写难看：**`cutfit` 会因为覆盖率太低而静默跳过**，切点退回 OCR 原值。
自检与补救见 `SKILL.md` 的 Step 1 / `tools/vadcheck.py`。

### 4.2 whisper 会在长静音上整句复读

片尾有长静音时，whisper 会把同一句话连出十几遍，而且**每个词的时间戳被压成
同一个时刻**（时长 0）。这种复读串会把全局对齐的锚点拖到**最后一遍**，于是
最后一段的 `t_end` 被拉到片尾（19 课末段因此多带出一整句 "Yes, let's go"）。

`cutfit._dedup_repeats()` 处理：某个 n 元组（n ≥ 4）连续重复 ≥3 次、
且重复块里 ≥60% 的词时长为 0 → 判定为幻觉，把第一个重复块**整块连同后面**剪掉
（真正那句话在更早的位置）。

### 4.3 `segcheck` 的孤立片段重听会幻觉

`segcheck.py` 把 `segNN.mp3` 单独喂给 whisper —— 片段短、没有上下文，
尾部静音上会凭空冒出像 "Always remember to check out our website for more
information. www.cdc.gov.uk" 这样的句子。所以它只能当**粗筛**看趋势，
**不要拿它的数字当绝对值**。

真正定量的是 `cuttail.py`：全部基于整片词级时间，三个指标
`尾多带 / 头多带 / 被切短`，可 `--list`、可 `--base` 对比精修前。

## 5. 兜底：手写覆盖

自动层判不出来 / 判错时，写 `tools/cutsfix.json`：

```json
{ "24": { "10": [129.30, 141.05] } }
```

例：24 课末段视频里说了两遍 "good job"，页面文本只有一遍 —— 自动层因为
`miss_tail>1` 不敢收尾，于是 b 停在 147.47（多出 1 个词 + 4.5 秒静音）。
手写值把它钉在第一个 "job" 之后。

改完照常：`refit_cuts.py <课号> --write` → `rebuild_audio.py <课号>` → `cuttail.py` 复查。

```bash
python tools/vadcheck.py 17 19 20 23 --write   # 补被 VAD 滤掉的词级时间戳
python tools/refit_cuts.py --write             # 用当前 words.json 重算切点并写回
```
